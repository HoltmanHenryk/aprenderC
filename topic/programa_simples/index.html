Idade do usuário
Agora faremos um programa simples, que:
-Pergunta a idade do usuário.
-Diz a idade digitada.
-Diz se o usuário é maior ou menos que 10 anos.
#include <stdio.h>

int main(void) {

  int idade = 0;

  printf("Digite sua idade:");
  scanf("%d", &idade);

  printf("Você tem: %d anos!\n", idade);

  if (idade > 10) printf("Você tem mais que 10 anos\n")

return 0;
Aqui, começamos incluindo a biblioteca stdio.h novamente.

Então declaramos main, como todo programa C.

Declaramos uma variavel, do tipo int, chamada idade, que inicialmente tem valor 0.

Informamos o usuário o que digitar (sua idade).

Usamos scanf() para capturar o que o usuário digitar, especificamos que queremos um numero inteiro ou decimál com %d. Falamos tambem para ele guardar o valor digitado na variavel idade.

Usamos printf novamente para escrever a idade do usuário na tela.

E finalmente, SOMENTE se a idade digitada for maior que 10, escrevemos 'Você tem mais que 10 anos' na tela.

Finalizamos a excução do programa informando que tudo ocorreu como experado.
